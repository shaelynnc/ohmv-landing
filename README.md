# OHMV Systems Landing Page

Landing page for [ohmvsystems.com](https://ohmvsystems.com) — the technology division of OHMV.

## Deploy

This site is deployed on [Vercel](https://vercel.com). Any push to `main` triggers an automatic redeploy.

## Editing

The entire site is a single `index.html` file. Edit it directly and push to see changes live.
